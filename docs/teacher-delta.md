# Що змінено відносно початкового архіву викладача

Джерело: наданий у Moodle `додаток_лр_4-5.rar` (RAR5, 10 основних записів). Початкові назви модулів збережено, але структура функцій та формат контейнера перероблені.

| Вихідний файл | Недоліки шаблону | Поточний стан |
|---|---|---|
| `key_manager.py` | Збереження salt і PBKDF2 без перевірки парольної фрази під час дешифрування, без повноцінної ротації | PBKDF2 600k, HMAC verifier, `active/retired`, 100 використань/90 днів |
| `crypto_aes.py` | GCM не автентифікує метадані заголовка; CBC MAC перевірявся до дешифрування, але не було контрольованого видалення часткових результатів | Аутентифікація header/AAD для всіх режимів; атомарний вихідний файл; CTR+HMAC |
| `aes_cli.py` | `--password` передавав секрет через argv, помилки `dec` друкувалися без ненульового exit status | `getpass`, код помилки `2`, REPL із перемиканням, перевірка параметрів |
| `logger_setup.py` | Директорія `logs/` могла бути відсутня; можливість запису шляху до файлів у логи | JSONL із мінімумом метаданих, POSIX 0600, окрема перевірка подій |
| `benchmark.py` | Лише інструкція, без реального вимірювача ресурсів | Запуски `benchmark.py`, CPU, elapsed, sampled RSS, медіани, SHA-256 |
| `tamper_demo.py` | Випадкове пошкодження непередбачуваного байта, без ідентифікації типу втручання | Підміна tag/ciphertext/header на копії файлу, негативні тести |
| `tests/test_roundtrip.py` | Файл містив тільки коментарі | Повний набір із 40 автоматичних тестів |

Доопрацювання виконані як навчальний проєкт, не як криптографічне рішення з незалежною сертифікацією.
